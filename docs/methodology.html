Metodologia

Pipeline

  1. Rasterizacao: PDF do Google Books / Internet Archive em 390 PNGs em 200 DPI
  2. Traducao trilingue: cada PNG enviado a Claude Opus 4.7 com prompt customizado para o estilo didatico do Isagogici, gerando JSON estruturado: latim transcrito + traducao pt + traducao en + definicoes + cross-references + tabelas + flags de incerteza
  3. QA estrutural: validacao automatica
  4. Construcao do site: HTML estatico servido pelo GitHub Pages

Reprodutibilidade

Todos os scripts no repositorio GitHub.

Sobre o projeto

Traducao colaborativa do Isagogicorum chronologiae canonum libri tres de Joseph Scaliger (Leiden, 1606). Iniciativa pessoal de Walter C. Neto (Sao Paulo, 2026), patrocinio proprio. Traducao por IA (Claude Opus 4.7), publicada como texto-semente para revisao academica colaborativa.

Projeto irmao (texto principal de Scaliger): De Emendatione Temporum
